# راهنمای تصاویر و رسانه — wallBoard

## ساختار فایل‌ها

- لوگو: `developer-source/public/images/logo.svg`
- تصاویر محصول: `developer-source/public/images/products/`
- تصاویر بنر fallback: `developer-source/public/images/hero/`
- خروجی پیش‌نمایش مستقل: `site/assets/images/`

## تصاویر محصولات

شش تصویر محصول در نسخه فعلی از عکس‌های مرجع ارسالی مالک پروژه ساخته شده‌اند. تصویرسازی با حفظ فرم، تعداد قطعات و بریدگی‌ها انجام شده است؛ فقط پس‌زمینه حذف و استایل خط دور، سایه و رنگ‌پردازی نرم اضافه شده. فرم قطعات نباید در طراحی‌های بعدی ساده‌سازی یا بازطراحی شود.

| فایل | محصول | محتویات |
|---|---|---|
| `pegboard-panel.webp` | پنل اصلی | ۱ پنل |
| `small-clips-set.webp` | گیره کوچک | ۳ عدد |
| `medium-clips-pair.webp` | گیره متوسط | ۲ عدد |
| `support-brackets-pair.webp` | گیره تکیه‌گاهی | ۲ عدد |
| `desk-stand-pair.webp` | پایه رومیزی | ۲ عدد |
| `large-clips-with-shelf.webp` | گیره بزرگ همراه تاقچه | ۲ گیره بزرگ + ۱ تاقچه |

این فایل‌ها WebP و دارای پس‌زمینه شفاف‌اند. کارت محصول، صفحه جزئیات، سبد و علاقه‌مندی‌ها از یک منبع تصویر استفاده می‌کنند. تصویر محصول با CSS ساخته نمی‌شود.

## تصاویر بنر

بنرهای fallback در `public/images/hero/` قرار دارند:

- `hero-panel.webp`
- `hero-workspace.webp`
- `hero-modular-kit.webp`

هر بنر یک تصویر واحد در ناحیه تصویر قالب فعلی است؛ متن، دکمه، ترتیب، تم و تصویر نسخه production از Django API دریافت می‌شوند. بنر هر ۵ ثانیه عوض می‌شود. اگر تصویر موبایل جداگانه تعریف نشود، تصویر دسکتاپ با `object-fit: contain` در موبایل نیز استفاده خواهد شد.

## مدیریت در Django Admin

برنامه‌نویس بک‌اند باید مدل تصویر محصول و مدل بنر را در Django ایجاد کند و امکان آپلود و مرتب‌سازی تصویر را در Django Admin فعال کند. فرانت‌اند تصویر را از فیلد `images[].url` محصول و `desktop_image` / `mobile_image` بنر دریافت می‌کند.

برای تصاویر محصول:

- WebP یا AVIF را ترجیح دهید؛ JPEG فقط برای سازگاری لازم.
- نسخه‌های responsive در اندازه‌های متناسب تولید کنید.
- محصول کامل و لبه‌های آن در تصویر بماند؛ crop نباید فرم قطعه را قطع کند.
- برای تصویر زمینه شفاف از PNG/WebP استفاده کنید.
- `alt`, `width`, `height` را ثبت کنید تا دسترس‌پذیری و CLS کنترل شود.

برای بنر:

- تصویر دسکتاپ و موبایل را جداگانه بارگذاری کنید.
- متن تیتر و دکمه را داخل فایل تصویر ننویسید؛ متن باید از فیلدهای مدل بنر بیاید تا در Django Admin قابل ویرایش و برای SEO قابل خواندن باشد.
- نسبت تصویر بنرها را در هر breakpoint ثابت نگه دارید.

## مسیرهای API

فرانت‌اند مسیرهای `/media/...` و URL کامل `https://...` را می‌پذیرد. فایل‌ها باید از Django Media یا CDN امن ارائه شوند. نوع فایل، حجم، ابعاد و نام فایل در زمان آپلود سمت سرور اعتبارسنجی شوند.
